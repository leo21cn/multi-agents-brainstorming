# 规则 05 · 记忆与检索

来源：`../../docs/architecture.md` 第 7 节（记忆架构）与第 6 节（检索服务、发言生成服务）；`../../docs/data-model.md`（记忆相关实体）。

## 记忆与知识分离

- 记忆：房间内讨论产生并沉淀的信息，随房间隔离。
- 知识：系统级三维知识库中的预置语料，跨房间复用。
- 二者在架构上分离：知识经 `rag/` 检索注入发言；记忆经记忆服务维护。不得把知识库当作记忆，也不得把房间转录写入知识库。

## 记忆分层

| 层 | 名称 | 作用域 | 生命周期 |
|----|------|--------|----------|
| L0 | 工作记忆 | 单次发言 | 临时，不持久化 |
| L1 | 会话记忆（转录） | 房间级 | 持久化 |
| L2 | 摘要记忆 | 房间级 | 持久化 |
| L3 | 立场记忆 | 智能体级（房间内） | 持久化 |
| L4 | 长期召回 | 房间级 | 持久化（本版未启用） |

- 写入：每次发言追加 L1；被触发发言的智能体追加 L3 要点；L1 达阈值触发增量摘要 L2，并记录其覆盖的消息范围。
- 读取：按令牌预算自高层向低层组装（L0、L2、L1 近期原文、L3、L4、知识检索结果），超出预算按该顺序裁剪。
- 压缩：经 `MemoryCompressor` 接口，本版实现滚动摘要；L3 按智能体独立压缩，只取该智能体自身要点。
- 淘汰：被摘要覆盖的原文不再进入上下文，但保留在 L1 中供结论生成与导出使用。

## 隔离边界

- 记忆不跨房间共享。
- L1、L2 对房间内成员可见，构成所有智能体的共享上下文。
- L3 默认仅服务所属智能体；是否进入其他智能体上下文可配置。

## 发言生成链路

按 `../../docs/architecture.md` 第 9.2 节：发言前读取记忆视图（L0、L2、L1、L3）组装上下文；检索绑定知识库；调用该智能体所选具体模型；发言后写回 L1 与 L3，并在达阈值时触发 L2 压缩。

## 来源标注

- 发言记录其引用的知识库来源；检索无命中时标记无知识库引用。
- 结论生成（第 9.4 节）读取命题与会话记忆，超阈值先摘要；为关键观点与分歧点标注来源智能体及其绑定知识库。
- 导出以会话记忆为准，按时间逐条保留来源智能体标识，条数与 L1 一致。
