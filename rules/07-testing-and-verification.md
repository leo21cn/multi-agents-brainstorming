## 身份夹具

- 既有讨论类用例的语义本来就是「主持人做这件事」，故身份在夹具层收敛：客户端包装器在建房响应里自动记下主持人身份，并按房间路径为后续 REST 调用注入两个身份请求头、为实时通道注入查询串。用例不必逐处补身份，既有断言也不必为此改写。
- 越权与无身份的用例一律显式表达：不带身份走 `client.raw`，以某位人类成员的身份走 `client.as_member(...)`。不得靠「忘记带身份」来表达越权——那会让夹具的一次改动悄悄改变用例的含义。
- 流式降级接口经包装器的 `stream` 方法调用；直接调底层客户端会绕过请求头注入，用例将以 401 失败而不是按预期语义失败。
- 身份校验先于房间查找，故「未知房间」一类的用例在无身份时得到 401 而不是 404。这不是缺陷，是不向匿名调用者泄露房间号是否有效。

## 功能验收标准（对应 SRS 第 8.3 节）

| 编号 | 验收项 | 通过标准 |
|------|--------|----------|
| A-1 | 编排越权 | 人类主持控制模式下，未被点名且未放行的智能体发言数为 0；自主举手只把智能体放入待发言队列，不产生任何发言；对人类成员同样成立——非主持人的成员未经放行或主持人 @ 指向而落库的消息数为 0 |
| A-2 | 插嘴闭环 | 举手信号产生、队列呈现、放行发言、驳回移出端到端成功；出队有放行、驳回与撤回三个原因，撤回与驳回的状态可分辨；放行一条已不在队列中的举手得到明确回执且不触发生成；队列混排智能体与人类成员两类主体且各自可分辨，放行人类举手授予一次发言权而不触发任何生成 |
| A-3 | 配置生效 | 每个智能体实际调用的模型与检索的知识库与其配置一致 |
| A-4 | 结论结构 | 结论文档四个固定章节按序齐全，额外章 0 至 10 个且各为一段针对本次讨论的文字，章名取自讨论自己的说法、不超 20 字、不与固定章重名，不出现指向他章的占位句；综合目标取系统级设置，设置留空或失效时回落房间阵容首位智能体 |
| A-5 | 来源标注 | 结论文档中关键观点与分歧点的来源标注完整率为 100% |
| A-6 | 导出一致 | 导出发言条数与房间发言数一致，且每条含来源标识；定向消息逐个列出全部受话者显示名，智能体在前、成员在后；多位人类成员各自按显示名标注，不出现「人类成员」通称 |
| A-7 | 上下文管理 | 讨论超长时自动滚动摘要，命题与关键结论线索不丢失 |
| A-8 | 异常处理 | 模型超时、检索无命中、空共享记忆等按异常流处理且不崩溃；意愿判定超时或异常按不举手处理，不产生举手也不中断讨论，且不据此撤回已有举手；结论综合的模型调用失败、回复不可解析或缺章时整份文档不生成、不落库部分内容，返回可重试的失败响应 |
| A-9 | 系统初始化 | 未满足最低要求时不能建房；初始化后可在管理界面增改配置并被新房选用 |
| A-10 | 管理访问令牌 | 缺失或错误令牌时配置写与敏感读返回未授权，正确令牌放行；房间侧只读接口开放；令牌可修改且改后旧令牌失效；缺省令牌 `111111` |
| A-11 | 首页初始化引导 | 未达标时访问首页跳转到管理界面初始化状态视图并提示配置；达标时首页正常呈现两个入口 |
| A-12 | 流式发言 | 首个增量前呈现阶段提示，随后文本逐段增长；正文增量以完整句为粒度下发，粒度不改变拼接口径；正文增量拼接结果与落库发言及消息列表一致，思考增量不参与拼接；导出条数仍与消息数一致；失败不落库部分内容；降级通道取得同样的增量序列 |
| A-13 | 配置热生效 | 改动智能体模型或连接配置后，房间界面重取配置即显示新值，下一次发言调用新模型；改动嵌入模型名后无需重启即按新值发起嵌入调用 |
| A-14 | 发言正文渲染 | 聊天区正文的 Markdown 语法渲染为对应结构且不再出现字面标记；流式气泡生成期间无元素子节点，收尾替换后完成渲染；脚本、事件属性、`javascript:` 链接与 iframe 等标记不被执行、不产生对应节点；渲染器不可用时回退为转义纯文本并保留换行；导出仍为原文 |
| A-15 | 定向提问 | 人类成员在聊天区以 @提及 定向提问阵容内的一个或多个智能体，问题以带受话者列表的人类消息落库并逐个呈现受话者显示名，随后自动触发各受话者流式发言；被触发者的上下文含提问者姓名与问题原文；任一受话者不在阵容内则整条消息被拒且不落库，房间已结束时同样拒绝；房间已有发言进行中时问题照常落库、应答排入待发言队列而不丢弃；`@名字` 未全部匹配到阵容内智能体时按匹配到的对象发送并提示；未被点名、未放行且未受定向提问的智能体发言数仍为 0；主持人的 @ 指向人类成员时授予其一次发言权而不触发生成，成员发出的 @ 只作受话者标注；导出条数仍与消息数一致，且每行以显示名标注来源与受话者 |
| A-16 | 发言节奏 | 正文以完整句收束，长度大体落在所属档位字数目标（快闪 240／均衡 600／深思 1800，思考预算无／256／1024）内；仅当超出 1.5 倍安全界（360／900／2700）时提前收束，收束点落在句界、截断标记落库、房间界面与导出行尾均呈现「篇幅所限，未展开」，自行收束的发言不带标注；开思考档位下思考增量先于正文增量到达，界面以默认折叠区呈现且可展开，收尾替换后消失；思考内容不落库、不进导出、不进上下文组装；无思考增量时不出现「思考中」阶段；端点拒绝思考参数时去掉参数重试一次并下发可见阶段文案；不支持思考分级的模型在管理界面被标注；档位改动即时生效；既有验收标准与差异化指标不回归 |
| A-17 | 控制面与演示选项 | 房间界面不呈现点名入口而点名协议上行仍可用；模拟举手入口位于举手栏，可见性由系统级界面与行为选项决定，选项改动后已打开的房间界面在重取配置时生效，房间待开始与已结束时该入口与队列动作均不可用；结束房间入口位于顶栏且保留确认；房间界面不存在切换房间入口；选项读取接口开放且响应不携带访问令牌，写入接口未携带或错误令牌时被拒，写入为全量覆盖两个开关；模拟举手产生的队列项不带自主来源标注，且不参与重判，其意图跨刷新原样不变、不被撤回；既有验收标准不回归 |
| A-18 | 自主举手 | 群发提问后数秒内出现来源为自主的举手项，意图文本可读且非空泛；举手期间没有任何智能体开始发言，放行后才发言；智能体发言落定同样触发一轮判定，刚发言者不被询问；已被点名或已被安排发言的智能体不询问，已持有自主举手的智能体同样重判；开关关闭后一次判定都不发生且已有举手不被改写或撤回，模拟举手入口不受影响；判定超时或异常不产生举手、不产生失败提示；房间待开始与已结束时不做判定；同房间并发两轮只跑一轮，轮次期间落定的新发言由尾随轮次补上 |

## 差异化效果指标（对应 SRS 第 8.4 节）

- 知识库来源一致率：绑定不同知识库的智能体，其发言引用来源与所绑知识库一致的比例，目标不低于 90%。
- 观点多样性：同一子问题下去重后由不同智能体产出的关键观点数量，及跨业务、方法论、技术三视角的覆盖。
- 视角可区分度：标注不同知识库来源的观点，人工评审判定为"视角确有差异"的比例。

## 真实模型接入

- 依赖默认接入真实模型（经模型连接配置的 OpenAI 兼容端点，默认 DashScope/Qwen），不以桩实现替代目标模型。
- 业务语料可用模拟数据，但模型接入、检索、记忆链路为真实链路。
- 需要真实模型调用的测试从模型连接或环境变量读取凭据；缺失凭据时明确跳过并报告，不得伪造通过。

## 工作方式

- 每次改动运行相关层测试。
- 提交前运行端到端基准命题验证，并核对第 8.3 节验收标准未被破坏。
- 新增或修改验收相关行为时，同步更新对应断言。
