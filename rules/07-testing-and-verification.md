# 规则 07 · 测试与验证

来源：`../../docs/srs.md` 第 8 节；`../../docs/implementation-plan.md`（M5.5 测试语料与用例、M6 自动化测试、M7 闭环）；`../../docs/testdata/`（测试知识库语料）。

## 测试分层

| 层 | 范围 |
|----|------|
| 单元 | 知识库解析与切分、向量检索、上下文组装与滚动摘要、来源标注、记忆读写与压缩、立场记忆隔离 |
| 集成 | 智能体发言生成链路（记忆读取 + 检索 + 模型调用 + 记忆写回）、举手与放行链路、结论生成链路、导出链路 |
| 端到端 | 以基准命题集跑通建房、配置、讨论、插嘴、结论、导出全流程 |
| 人工评估 | 差异化效果与结论文档质量的评审打分 |

## 测试语料与用例来源

- 知识库测试语料取自 `../../docs/testdata/`（三维度、含来源说明），由 `scripts/seed_corpus.py` 入库。
- 依据语料的测试用例（锚点、绑定限定、语义检索）见实施计划 M5.5 Task P2；基准命题集见 `scripts/benchmark_propositions.yaml`。
- 语料以自攥要点承载，标注来源与性质，不逐字转载来源正文。

## 功能验收标准（对应 SRS 第 8.3 节）

| 编号 | 验收项 | 通过标准 |
|------|--------|----------|
| A-1 | 编排越权 | 人类主持控制模式下，未被点名且未放行的智能体发言数为 0 |
| A-2 | 插嘴闭环 | 举手信号产生、队列呈现、放行发言、驳回移出端到端成功 |
| A-3 | 配置生效 | 每个智能体实际调用的模型与检索的知识库与其配置一致 |
| A-4 | 结论结构 | 结论文档七个章节齐全 |
| A-5 | 来源标注 | 结论文档中关键观点与分歧点的来源标注完整率为 100% |
| A-6 | 导出一致 | 导出发言条数与房间发言数一致，且每条含来源智能体标识 |
| A-7 | 上下文管理 | 讨论超长时自动滚动摘要，命题与关键结论线索不丢失 |
| A-8 | 异常处理 | 模型超时、检索无命中、空共享记忆等按异常流处理且不崩溃 |
| A-9 | 系统初始化 | 未满足最低要求时不能建房；初始化后可在管理界面增改配置并被新房选用 |

## 差异化效果指标（对应 SRS 第 8.4 节）

- 知识库来源一致率：绑定不同知识库的智能体，其发言引用来源与所绑知识库一致的比例，目标不低于 90%。
- 观点多样性：同一子问题下去重后由不同智能体产出的关键观点数量，及跨业务、方法论、技术三视角的覆盖。
- 视角可区分度：标注不同知识库来源的观点，人工评审判定为"视角确有差异"的比例。

## 真实模型接入

- 依赖默认接入真实模型（经模型连接配置的 OpenAI 兼容端点，默认 DashScope/Qwen），不以桩实现替代目标模型。
- 业务语料可用模拟数据，但模型接入、检索、记忆链路为真实链路。
- 需要真实模型调用的测试从模型连接或环境变量读取凭据；缺失凭据时明确跳过并报告，不得伪造通过。

## 工作方式

- 每次改动运行相关层测试。
- 提交前运行端到端基准命题验证，并核对第 8.3 节验收标准未被破坏。
- 新增或修改验收相关行为时，同步更新对应断言。
