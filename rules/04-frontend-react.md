# 规则 04 · 前端规范

来源：`../../docs/architecture.md` 第 4、6 节；`../../docs/view-spec.md`（视图编号 VW-A1~A5、VW-R1~R5）；`../../docs/prototype/`（界面与视觉基线）。

## 技术

- React + TypeScript + Vite。
- 两层界面：`src/admin/` 管理界面（系统级配置），`src/room/` 房间界面（群聊）。
- 视觉与布局以 `../../docs/prototype/` 为基线：浅色极简，房间与管理后台共用同一套设计令牌与「火花会 Sparkwave」品牌标识。

## 界面职责

管理界面：

- 知识库维护：三维度文档上传与增改。
- 智能体配置：选择具体模型、绑定知识库、挂载角色提示词卡，及后续调整。
- 展示初始化状态，未满足最低要求时给出引导。

房间界面：

- 建房：填写命题、从已配置智能体中选用阵容、选择编排模式。
- 邀请人类成员、指定主持人。
- 聊天区：人类与智能体发言分区展示，显示来源标识。
- 举手状态呈现与主持人放行、驳回。
- 结论生成与完整发言记录导出入口。

管理界面与房间界面不得混用；系统级配置只在管理界面完成。

## WebSocket 客户端

- `src/ws/` 统一封装连接、重连与事件分发。
- 事件类型与后端接入层保持一致（发言、举手状态、成员变更、房间状态、发言失败提示；上行为点名、放行、驳回、人类发言）。
- 房间状态集中管理：消息流、举手队列、成员与角色、房间状态。

## 展示约定

- 人类发言与智能体发言区分样式，并显示来源智能体。
- 举手队列可见，主持人可放行或驳回。
- 结论文档与导出记录中的来源标注在界面上可读。
