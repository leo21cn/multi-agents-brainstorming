# 规则 03 · 后端 Python 规范

来源：`../../docs/architecture.md` 第 4、6、8 节；`../../docs/data-model.md`；`../../docs/implementation-plan.md`（模块与接口契约）。

## 语言与风格

- Python 3.11+。
- 全量类型标注；公共函数、服务方法、领域实体均标注参数与返回类型。
- 异步优先：接入层与涉及 I/O 的服务用 async；避免在异步路径中做阻塞调用。
- 同步阻塞的模型调用与生成迭代不得在事件循环内直接 await：放入工作线程执行，增量经线程安全的方式回到事件循环后再下发，否则同一进程内所有客户端的实时通道同时停摆。由 async 端点直接调用的同步工作（如放行后的一次性发言生成）经 `asyncio.to_thread` 交回线程池。
- 懒建单例（数据库引擎、向量库）须持同一把 `threading.Lock` 并双检：同步端点跑在线程池里，房间页启动即并发拉数份配置，两个线程同时进 Chroma 的 `PersistentClient` 会因其共享系统注册表的竞态抛异常，表现为冷启动时几个只读接口一起 500。
- 命名：模块小写下划线；类用帕斯卡命名；常量全大写；与领域术语一致（房间 room、命题 proposition、智能体 agent、知识库 knowledge_base、人类成员 member、发言 message、举手 raise_hand、发言权 floor、结论文档 conclusion_doc）。

## 分层落位

| 目录 | 职责 |
|------|------|
| `api/` | REST 与 WebSocket 接入、协议转换、请求校验；`identity.py` 集中承载成员身份解析、恒定时间比较、主持人与成员两级门控依赖与三句拒绝文案；`ws.py` 另承载每房间的待发言 FIFO、在途守卫与收束钩子 |
| `services/` | 配置、房间、发言、结论、来源标注等业务用例 |
| `orchestration/` | 调度策略、待发言队列、意愿判定与自主举手轮次；`floor.py` 承载发言权集合与「主持人的 @ 才授予」的判定函数；`ag2_adapter.py` 为无运行时调用方的框架集成点 |
| `rag/` | 文档解析切分、嵌入、向量库、检索 |
| `memory/` | 上下文组装、滚动摘要、记忆服务（L1/L2/L3） |
| `models/` | 模型提供方接口、OpenAI 兼容实现、离线演示实现、发言档位解析与句界门控 |
| `persistence/` | SQLite 引擎与建库；产出文件由结论文档服务写入数据目录 |
| `domain/` | 实体与枚举 |

- 领域实体用 dataclass 或 pydantic 模型，集中在 `domain/`。
- 服务之间通过领域实体与接口交互，不互相穿透内部实现。

## 错误处理

按 `../../docs/architecture.md` 第 9 节的异常流处理，不吞异常、不静默失败：

- 模型调用超时或失败：上报房间并允许重新发起提问。
- 流式生成中途失败：不落库部分内容，仅下发失败提示；落库发生在全部增量到达之后。
- 房间已结束：拒绝新增发言与人类发言，REST 返回 422，实时通道回以失败提示或 `rejected`。
- 人类发言的任一受话智能体不在房间阵容内、或任一受话成员不在房内成员名单中：整条拒绝，REST 返回 422，实时通道回 `rejected`；不落库、不派发。
- 成员身份缺失或令牌不符：REST 返回 401；实时通道在接受连接之前以 1008 关闭并给出原因，不进入接收循环。
- 非主持人调用讨论控制类端点：返回 403 并给出「该操作只有主持人可执行」；实时通道回 `rejected`，连接不中断。身份校验先于房间查找，故不向匿名调用者泄露房间号是否有效。
- 非主持人的成员在无发言权时发言：返回 403 并说明取得发言权的两条途径，消息不落库。
- 主持人调用「为自己举手」：返回 403，他有话直接说，不必举手。
- 进房昵称留空、与既有成员重名或与阵容内智能体同名：拒绝并给出可操作的提示；房间已结束时拒绝新成员加入，既有成员仍可认领。
- 认领时管理令牌不正确：返回 403，不发放新令牌。
- 检索失败（嵌入端点不可达、向量维度不匹配）：收束为发言错误并上报，发生在任何增量下发之前，不落库部分内容。
- 端点拒绝思考参数（HTTP 400 且错误体指明思考相关参数）：去掉思考参数重试一次，并下发一条可见的阶段文案说明已按关思考生成，不静默降级。重试保留档位本体，安全界不因重试失效；已下发过任何片段则不重试，否则客户端看到重复内容；模型名错误一类的 404 原样抛出，不落入该重试。
- 提前断流后必须关闭底层流，否则连接悬挂。
- 向量库打开失败（目录被占用、路径不可写）：让异常冒出，不降级到内置实现。语料入库到真实向量库后内置实现是空的，静默降级会让检索恒返回零命中且调用方看不到异常，直接摧毁来源标注口径。仅在向量库依赖未安装时降级，并输出告警日志。
- 检索无命中：标记无知识库引用，不阻断讨论。
- 会话记忆为空：拒绝生成结论并提示。
- 结论综合的模型调用失败、超时或回复不可解析（不是 JSON 对象、缺必写章、章名为空或超 20 字、与固定章重名、两章同名、额外章超 10 个、值非字符串或为空）：整份文档不生成、不落库部分内容，返回可重试的失败响应；不得回落占位句凑章数。模型把中文引号写成半角双引号而使回复成为非法 JSON 时，先按扁平对象的结构给内层引号补转义再解一次，仍不可解析才判为失败——补转义只修编码，不猜章节也不猜标题。
- 上下文超阈值：先滚动摘要再生成。
- 上传文档格式不支持或为空：拒绝入库并提示。
- 访问令牌缺失或错误：返回 401，不回显期望值；令牌比较按 UTF-8 字节做恒定时间比较，`hmac.compare_digest` 不接受含非 ASCII 的字符串。成员令牌走同一个工具函数，不得在路由内各自实现一份比较。

## 日志

- 记录模型调用、检索命中、发言生成的关键字段（房间、来源成员、模型连接、模型名、引用知识库、耗时）。
- 日志不得包含 API Key、管理后台访问令牌、人类成员令牌或完整凭据。

## 配置

- 环境级配置（如环境变量提供的默认凭据、阈值与预算）从环境变量读取，集中在一个 settings 模块；不在业务代码散落读取环境变量。
- 模型连接的地址与凭据为系统级可配置项，存于持久层并经掩码读取；API Key 不得下发前端明文、不得入日志与导出。
- 系统级配置改动对后续调用即时生效，不依赖重启：对话提供方在每次发言时按智能体当前配置构建，嵌入提供方按次经工厂解析并以（地址、凭据、嵌入模型名）为键缓存，键变化即重建。
- 发言节奏档位为智能体级可配置项，与提示词同处一处配置；每次发言时按当前档位与当前模型名解析，改动即时生效于下一次发言。
- 档位的字数目标、安全界倍数与思考预算集中在档位参数表，不散落到发言链路各处；句界切分与流式门控集中在一个模块，两条调用路径与两个提供方共用，不得各自实现一套切分；思考预算的能力判定以模型名前缀为键，供应商类型字段是自由文本，不得用作能力表的键。
- 嵌入模型名为连接上的可空配置项，空值按提供方缺省值解析；不在实现层硬编码具体模型名。
- 管理后台访问令牌为系统级可配置项，存于系统设置表而非环境变量；缺省值在建库时播种，修改即时生效。
- 结论综合所用的模型连接与模型名同为系统级可配置项，存于系统设置表且不做缺省播种；每次生成结论时读取，改动即时生效。设置留空或已失效（连接被删、模型名不在可用列表内）时回落房间阵容首位智能体的连接与模型，故配置漂移表现为降级而非阻断。综合调用的提供方经与发言同一个工厂按连接解析，不得在结论服务内另建一份客户端缓存。
- 阈值与预算集中在 `settings.py` 并由环境变量提供（上下文字符预算 `SPARKWAVE_CTX_TOKEN_BUDGET` 缺省 6000、摘要触发阈值 `SPARKWAVE_SUMMARY_TRIGGER_TOKENS` 缺省 8000），不硬编码进业务逻辑；两者都按字符数计量，配置项名沿用令牌的历史叫法。检索条数为检索方法的缺省参数（5），未进配置。
