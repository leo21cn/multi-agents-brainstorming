# 规则 06 · 安全与凭据

来源：`../../docs/srs.md` 第 7 节、`../../docs/architecture.md` 第 11 节。

## 凭据

- 模型连接的 API Key 由管理员在管理界面配置，入库存储但受保护。
- 受保护的具体要求：界面掩码呈现、仅管理员可读、日志与导出不含、不下发前端明文。
- 环境变量可作为默认值或覆盖；不得把环境变量内容回写为明文配置或日志。
- 禁止将 API Key 写入代码、测试夹具、文档或提交信息；不提交任何含凭据的文件。

## 上传

- 知识库文档做格式校验与大小限制；不支持或为空的文档拒绝入库并提示。
- 上传文件按知识库与文档标识归档于文件系统。

## 访问

- 房间访问方式经邀请分发；本版不做细粒度鉴权与多租户隔离。
- 人类成员以昵称或登录身份区分，昵称在房间内唯一可辨。

## 导出

- 结论文档与完整发言记录导出文件按房间归档，供下载。
- 导出内容含来源智能体标识，不含凭据或系统级敏感配置。

## 边界

- 本版为单机演示，不承诺跨机同步、房间隔离与并发治理；相关防护不在此版范围内，不得因此弱化凭据与上传校验两条硬约束。
