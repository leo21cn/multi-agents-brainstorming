# 规则 06 · 安全与凭据

来源：`../../docs/srs.md` 第 7 节、`../../docs/architecture.md` 第 11 节。

## 凭据

- 模型连接的 API Key 由管理员在管理界面配置，入库存储但受保护。
- 受保护的具体要求：界面掩码呈现、仅管理员可读、日志与导出不含、不下发前端明文。
- 环境变量可作为默认值或覆盖；不得把环境变量内容回写为明文配置或日志。
- 禁止将 API Key 写入代码、测试夹具、文档或提交信息；不提交任何含凭据的文件。

## 访问令牌

- 管理后台以访问令牌保护：令牌存于系统设置（键 `admin_token`），缺省 `111111`，可在管理界面修改。
- 令牌为敏感值：不以明文回传前端、不入日志与导出、界面掩码输入；禁止写入代码、测试夹具、文档或提交信息。
- 校验采用恒定时间比较；缺省令牌于建库时自动播种，记录缺失时按缺省值兜底。
- 保护范围：系统级配置的写操作与敏感读操作（模型连接、文档、界面与行为选项写入、结论综合模型设置与语音转写模型设置的读与写）须携带令牌；房间侧只读接口（智能体、知识库、初始化状态、界面与行为选项）与房间流程保持开放，不阻断参与者。界面与行为选项属界面偏好与编排偏好而非凭据，其开放响应只含选项本身，不得携带访问令牌或任何其他设置值。结论综合模型设置与语音转写模型设置给出的是连接取向而非房间界面所需，故读写都须令牌，不得比照界面与行为选项开放只读。

## 成员令牌与房间权限

- 人类成员令牌在进房或认领时发放，只在发放那一刻随响应返回一次；任何读接口、日志与导出都不含该值。
- 成员序列化一律经不含令牌的响应模型输出，不得裸返实体字典：实体加了列，裸返就会把令牌发给所有打开房间页的人。
- 令牌明文入库，校验走同一个恒定时间比较工具函数（按 UTF-8 字节）。不哈希的理由是同库已明文存着模型 API Key，加哈希只挡住「能读库的人」，而能读库的人本来就能改库；真正的泄露口在序列化，堵住的是那一处。
- 成员令牌同样不得写入代码、测试夹具、文档或提交信息；测试里现造令牌，不得复用线上库中的值。
- 前端只把成员标识与令牌存在标签页级存储中，不存浏览器级：单机演示下同机开多个标签即为多个人，存到浏览器级会让第二个成员继承第一个的身份。显示名与是否主持人一律从成员名单重新解析，本地不留角色快照。
- 实时通道在接受连接之前校验身份，缺失或失效以 1008 关闭，不进入接收循环、不接收任何广播。REST 侧同一套身份经两个请求头携带，两条通道的门控范围必须一致。
- 讨论控制类操作在服务端只认主持人：开始、移交主持、结束、生成结论、导出、点名发言、模拟举手、放行、驳回。界面不呈现入口不构成依据，越权调用一律拒绝且状态不变。
- 人类消息的来源取自连接身份，请求体里没有可填的来源字段，故无从替别人发言，也无从替自己放行。
- 本版不做令牌吊销与过期：凭管理令牌认领即重新发放，是唯一换令牌的途径。

## 上传

- 知识库文档做扩展名与可解码性校验：只收 `.md` 与 `.txt`，且须能按 UTF-8 解码；不支持或为空的文档拒绝入库并提示。不设大小上限。
- 上传的原件不落盘：文档只在内存中解码、切分与嵌入，入库产物为分块行与向量。文档表的 `file_ref` 记下按知识库与文档标识构成的约定路径，该路径下无文件，不得据以读取原件。

## 不可信文本

- 模型输出与人类发言正文均为不可信文本。房间界面按 Markdown 渲染时以 `html:false` 解析：源文本的尖括号转义为文字，输出标签全部由渲染器生成，安全由配置保证而非事后消毒，故不引入额外消毒器。
- 渲染器关闭图片规则，正文不得触发外部请求；`javascript:` 一类链接协议由渲染器内置校验拦截，裸地址不自动成链。
- 流式增量以文本内容写入，不进入 `innerHTML`；发言正文之外的用户可见文本一律转义后插入，接口返回的正文与文件名不得直接拼接为 HTML。
- 升级或替换渲染器时须重新核对配置项与输出的标签集合，并同步更新 vendor 出处记录的版本与校验值。

## 访问

- 房间访问方式经邀请链接分发；房间标识即读凭据，读接口不加身份，此为单机演示的既有取舍。除管理令牌与成员令牌外，本版不做多租户隔离；不得顺手给读接口加身份门控，那会把「读既有产出」也挡在门外。
- 人类成员以昵称区分，昵称在房内人类成员中唯一，且不得与阵容内智能体同名——同名会让 `@` 解析出现二义。
- 服务仍绑本机回环地址；多人类成员以同机多标签或多浏览器演示，每标签一个人。把监听范围扩到本机之外会同时改变读凭据的含义，须连带重估本节各条。

## 导出

- 结论文档与完整发言记录导出文件按房间归档，供下载；下载对全体成员开放。
- 导出内容含来源标识（智能体名与人类成员的显示名），不含凭据、成员令牌或系统级敏感配置。

## 边界

- 本版为单机演示，不承诺跨机同步、房间隔离与并发治理；相关防护不在此版范围内，不得因此弱化凭据、访问令牌与上传校验三条硬约束。
